# {標題}

## 高階結論

- **現象**：實際觀測到的問題。
- **根因**：已有證據支持的原因；尚未確定時明確標記。
- **影響**：已確認的影響範圍。
- **目前狀態**：尚未處理、已緩解、已修復或待驗證。
- **下一步**：最小可執行的修復、驗證或決策。

## 調查背景

### 觸發原因
- 事件/問題描述
- 發現時間與方式

### 調查範圍

- 調查時間範圍

## 證據與操作邊界

| 類別 | 內容 |
|------|------|
| 已直接驗證 | 原始碼、日誌、實測或原始資料支持的結論 |
| 推論 | 由證據推導但尚未直接證明的結論 |
| 未驗證 | 本次未取得證據的項目與原因 |
| 已執行 | 本次實際進行的讀取或修改 |
| 明確未執行 | 未做的寫入、部署、重啟、流量或資料異動 |
